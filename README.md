# 🎮 GameZone

**GameZone** adalah aplikasi katalog game berbasis Flutter yang menampilkan informasi mengenai berbagai game, mulai dari kategori, tanggal rilis, deskripsi, hingga kebutuhan sistem.

## ✨ Fitur

- **Home Page**: Menampilkan game populer, game terbaru, dan kategori game.
- **Daftar Game**: Menampilkan daftar game yang tersedia.
- **Detail Game**: Menampilkan informasi lengkap tentang game yang dipilih.
- **Data JSON**: Menggunakan file JSON lokal sebagai sumber data dummy.
- **Navigasi**: Memungkinkan pengguna berpindah halaman dan melihat detail game.

## 🛠️ Teknologi

- Flutter
- Dart
- JSON
